# Contributing

Thanks for helping! This repo accepts changes through pull requests only.

1. Fork the repo and create a branch.
2. `npm install`, then `npm run watch` and press **F5** in VS Code to try your change.
3. Make sure `npm run package` succeeds.
4. Open a pull request describing what changed and why.

Every pull request needs the maintainer's approval before it can be merged,
and CI runs for first-time and outside contributors only after the maintainer approves it.

For security issues, see [SECURITY.md](SECURITY.md) instead of opening an issue.
